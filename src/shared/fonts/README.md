# Brand fonts

These WOFF2 files are the regular/bold Epilogue and regular IBM Plex Mono fonts
served by https://www.chaoticwizard.com/ and are bundled for offline use.
Their SIL Open Font License notices are included here and copied into
`dist/licenses` when building the application.

Source assets:
- Epilogue regular: `https://www.chaoticwizard.com/_astro/fonts/050fefeb89ae2b97.woff2`
- Epilogue bold: `https://www.chaoticwizard.com/_astro/fonts/8683aff8a3519d00.woff2`
- IBM Plex Mono regular: `https://www.chaoticwizard.com/_astro/fonts/a4eedeaa0f71488f.woff2`
