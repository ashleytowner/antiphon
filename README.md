# RPG Music Player

A local-first Electron application for tabletop music, ambience, and sound effects.

## Development

Requires Node.js 24 and npm. Run `npm install`, then `npm start`.

- `npm run build`: type-check and bundle the desktop application.
- `npm test`: run focused automated checks.
- `npm run package`: create a package for the current operating system.

Implementation is in progress. Audio files stay in their original library folder.
